# Create an ADR

Read `docs/decisions/README.md` and `docs/decisions/0000-template.md`. Use the next sequential ID and keep one decision per file.

Record the real constraint, decision, consequences, security and migration effects, and credible alternatives. Set an owner and `verified_against` reference that a maintainer can check. Add the ADR to the index and update superseded records explicitly.

Do not create an ADR for an easily reversible local implementation detail.
