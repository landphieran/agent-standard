# Six-layer architecture browser brief

Interactive, business-facing explanation of the Agent Standard six-layer architecture.

The site includes:

- a system context view;
- expandable layer descriptions;
- a business capability map;
- the repository adoption workflow;
- an evidence-led pilot and value case;
- risks, dependencies and leadership decisions; and
- a presenter kit with recommended adoption artifacts.

## Local use

```bash
npm install
npm run dev
```

Run `npm test` to build the deployable site and verify the rendered content.
